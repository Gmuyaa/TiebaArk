# TiebaArk（贴吧Ark）

面向 HarmonyOS NEXT 的第三方贴吧客户端，采用 ArkTS、ArkUI 和鸿蒙原生界面开发。项目仍在开发中，与百度官方无关联。

## 主要功能

| 分类 | 功能 |
| --- | --- |
| 浏览与搜索 | 首页推荐、关注、热榜；关注吧列表、吧内分类、搜吧、搜帖子、搜人及吧内搜索 |
| 帖子与媒体 | 帖子详情、楼中楼、表情、大图浏览与图像超分；视频瀑布流、全屏播放与评论 |
| 互动 | 点赞、关注用户与贴吧、逐吧签到、收藏、文字回复、系统分享 |
| 个人内容 | 个人主页、公开帖子与回复、关注与粉丝列表、我的帖子／回复、收藏和本地历史 |
| 吧资料 | 吧简介、吧规与吧务团队 |
| 外观与偏好 | 外观、字体大小 |
| 账号与设置 | 网页／Cookie 登录、头像、缓存清理、权限与隐私信息 |



## 登录与隐私

支持网页登录和手动 Cookie 登录。Cookie 包含账号凭据，请勿分享给他人或提交到仓库。

登录凭据由系统安全存储保存，退出登录可清除；浏览历史等数据保存在本机。公开页面只展示服务端允许访问的数据，尊重用户隐私设置。

## 源码构建

公开源码仅包含应用、正式资源及必要工程配置。使用 DevEco Studio 26 配套工具链，目标 SDK 为 26.0.0。

1. 将 `build-profile.example.json5` 复制为 `build-profile.json5`，再用 DevEco Studio 打开项目。
2. 同步工程依赖，选择 `entry` 模块的 `default` 目标构建 HAP。
3. 安装到设备前，在本机配置自己的签名与匹配设备的 Profile；签名配置和材料不要提交到仓库。
